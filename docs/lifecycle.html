Smart Agriculture · Punjab

From a one-shot pipeline to a closed loop

What the system does today, what the autonomous version does instead, and the one stage that cannot come along.

Today: one measurement, one answer

The farmer names the crop, the pipeline takes a single satellite composite over the whole district, and a calendar fills in everything that happens afterwards. Nothing looks at the field again.

The target: a loop that re-enters itself

The same field is re-observed every five days. Each stage hands to the next, and after harvest the loop returns to monitoring instead of ending.

The stage that cannot come along

Moving to field scale fixes the dilution that sank yield prediction. It does not fix the label, and the label is the reason it failed.

Do not train a field-level yield model on district averages. It is the one path in this diagram that looks like engineering work and is actually a category error.

What to find first

20–30 real harvest dates, to ±3 days. Nothing else is close. Without them the headline feature is an untested claim; with them it is a measured result with a detection rate and a mean lag. This is a week of phone calls, not a technical problem.

Then field polygons for ten to twenty demo farms, each at least a hectare — below roughly half a hectare, edge pixels dominate the statistics.

Everything else in the loop is pipeline work against data already on disk.
